## Использованные команды
1. При выполнении домашнего задания были использованы следующие команды:
   - `git rebase [-i]` — для изменения истории коммитов (использовались `squash` и `reword`), а также переноса веток.
   - `git cherry-pick` — выбор отдельных коммитов для переноса в текущую ветку.
   - `git branch -f <branch-name> <хэш>` — для переноса веток при переименовании коммитов.
   - `git push origin <branch-name>` — для отправки изменений в удалённый репозиторий.
